# NIGHTFALL — Ghost Protocol

NIGHTFALL — прототип рабочей станции threat intelligence для исследования связей между публичными цифровыми активами. Граф — основная поверхность приложения: он поддерживает поиск, фильтры, выбор нескольких сущностей, перемещение узлов, раскрытие соседей, режимы представления и рабочие расследования.

## Запуск

Требуются Node.js 20 или новее.

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`. Для production-сборки выполните `npm run build`, затем `npm start`.

## Возможности

- Force, иерархический, радиальный, временной, доказательный режимы и режим путей риска.
- Поиск по именам, типам и атрибутам; фильтры типов; выделение соседей и приглушение нерелевантных связей.
- Перемещение по полотну, масштабирование, центрирование, сворачивание ветвей, закрепление и история изменений раскладки.
- Inspector с источником, временем обнаружения, достоверностью, атрибутами и связанными доказательствами.
- Локальные рабочие расследования, заметки и аннотации, импорт и экспорт JSON.
- Демонстрационный граф помечен как Demo. Он не содержит подтверждённых реальных результатов и загружается локально без подключения внешних источников.

## Хранение и безопасность

В этом прототипе нет подключённого backend API, учётных записей или совместного доступа. Раскладка и рабочие расследования хранятся локально в браузере. Используйте только публичные данные и активы, для которых у вас есть разрешение на анализ. Не добавляйте персональные данные или секреты. Данные графа являются учебными и не должны использоваться для принятия решений о реальных организациях.

## Синтетический граф цепочек инъекций

Файл [examples/synthetic-injection-chains.json](./examples/synthetic-injection-chains.json) содержит 10 учебных цепочек и более 100 узлов со связями для стресс-проверки импорта и визуализации. В графе используются только разрешённые схемой типы сущностей и отношений; все цепочки помечены как Demo и hypothesis.

Это сценарии анализа canary-событий, а не рабочие эксплойты: исполняемой нагрузки и сетевых запросов нет, IP-адреса относятся к RFC 5737, а домен использует зарезервированную зону `.example`. ATT&CK IDs указаны как учебные кандидаты, а не как подтверждённая классификация.
