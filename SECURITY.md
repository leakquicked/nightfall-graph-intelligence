# Security Policy

## Project scope

This repository is an educational project or prototype. It is not a managed security service and does not provide a security-response SLA. Do not rely on it as the sole control protecting production systems or sensitive data.

## Reporting a concern

- Do not publish passwords, access tokens, private logs, personal information, or weaponized proof-of-concept material in a public issue.
- If GitHub private vulnerability reporting or a security advisory is enabled for this repository, use that private channel.
- Otherwise, contact the maintainer through the public contact details on the GitHub profile and ask for a private reporting route before sharing sensitive details.
- Include the affected version or commit, a concise impact description, and safe reproduction steps. Redact identifying data.

## Safe use

Use the project only with data and systems you own or are explicitly authorized to analyze. Findings generated by educational rules or heuristics require human verification and are not proof of compromise or vulnerability.

## Supported versions

Only the latest state on the default branch is maintained for learning and demonstration purposes. No guaranteed response time or backport policy is offered.
